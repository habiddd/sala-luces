# Cotas temporales al seleccionar — plan

**Goal:** Al seleccionar un carril, una luz o una toma, la vista 3D muestra cotas (como las cotas temporales de Revit): línea con marcas en los extremos y la distancia en metros (`"1.50 m"`) en el centro.

**Approved by user (2026-11-03):**
- Carril: en X, distancia al carril vecino de cada lado (los dos si está entre dos); si no hay vecino en un lado, hasta esa pared (Oeste x=0 / Este x=ancho). Además, cota total a cada pared **solo** en el lado donde sí hay vecino (si no, sería repetida).
- Luz: en X, las mismas cotas que su carril (a la altura y z de la luz). En Z, a lo largo de su carril: a la luz vecina del mismo carril por cada lado; si no hay, hasta la pared Sur (z=0) / Norte (z=largo); además cota total a cada pared solo en el lado donde hay vecina.
- Toma: a lo largo de su pared, distancia a cada esquina (pos y largo_pared − pos).
- Distancias entre ejes. Cotas de longitud < 0.005 m no se dibujan. Vecino = el más cercano con coordenada estrictamente menor / mayor.

## Interface (all in `src/escena.rs`; only file touched)

```rust
pub struct Cota { pub a: V3, pub b: V3, pub texto: String }   // texto = format!("{:.2} m", (b - a).len())
pub fn cotas(m: &Montaje, sel: &Sel) -> Vec<Cota>;            // empty if the selected id doesn't exist
pub const COLOR_COTA: egui::Color32;                          // amarillo (255, 210, 0)
```
Placement (so cotas don't overlap):
- Carril (y = altura_carriles): neighbor/wall cotas at z = largo/2; total-to-wall cotas at z = largo/2 + 0.4.
- Luz: X cotas at (y = centro_luz.y, z = luz.z), totals at z = luz.z + 0.4 (clamped inside [0, largo]); Z cotas at (x = carril.x, y = centro_luz.y), totals at x = carril.x + 0.4 (clamped inside [0, ancho]).
- Toma: along the wall at the toma point (`Pared::punto`), from the corner pos 0 to pos, and pos to the other end.

`construir(m, Some(sel))` appends, for each `Cota`: a `Linea(a, b, 1.5)` with `COLOR_COTA`, two tick lines at a and b (vertical, ±0.08 m in y), and a `Texto` at the midpoint with `texto`; all with `sel: None`, `resaltado: false`. Texts must be drawn in their prim colour (check `dibujar`; if it ignores the colour, make it use it).
