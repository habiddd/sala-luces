## Task A — model (`src/modelo.rs` only)

```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub enum TipoObjeto { Silla, Mesa, Maniqui, Caja }
impl TipoObjeto {
    pub const TODOS: [TipoObjeto; 4];
    pub fn nombre(self) -> &'static str;          // "Silla", "Mesa", "Maniquí", "Caja"
    pub fn medidas(self) -> (f32, f32, f32);      // (ancho, fondo, alto): Silla (0.45,0.45,0.90) Mesa (1.20,0.70,0.75) Maniqui (0.50,0.30,1.75) Caja (1.0,1.0,1.0)
}
#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct Objeto { pub nombre: String, pub tipo: TipoObjeto, pub x: f32, pub z: f32,
                    pub rot: f32 /* grados */, pub ancho: f32, pub fondo: f32, pub alto: f32 }
// Montaje gets: #[serde(default)] pub objetos: Vec<Objeto>   (old files without it still load)
impl Montaje {
    pub fn anadir_objeto(&mut self, tipo: TipoObjeto) -> String; // name "<tipo.nombre()> <n>" first free n ≥ 1; x = ancho/2, z = largo/2, rot 0, default medidas
    pub fn borrar_objeto(&mut self, nombre: &str);
    pub fn renombrar_objeto(&mut self, viejo: &str, nuevo: &str) -> Result<(), String>; // trim; Err empty or duplicate; nothing changes on Err
}
```

## Task B — scene + UI (`src/escena.rs`, `src/app.rs`)

**Shapes (escena `construir`)** — local frame: origin at the object's centre on the floor, local X = ancho, local Z = fondo (+Z = front), Y up. World = rotate local (lx, lz) by `rot` degrees about Y: `x = o.x + lx·cos r + lz·sin r`, `z = o.z − lx·sin r + lz·cos r`. Each part is a box given as (centre, size) in fractions of (w = ancho, h = alto, d = fondo); build all 8 corners in local space, rotate, emit the 6 faces (like the existing box helper, but rotated).
