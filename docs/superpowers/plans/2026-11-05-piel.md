# Piel simulada y tono editable en el maniquí — plan

**Goal:** el maniquí se sombrea como piel (brillo especular de la capa grasa + dispersión subsuperficial que suaviza la transición luz/sombra y la tiñe de rojo) en el raster y en el trazado, y su tono de piel se elige en el panel derecho (presets medidos + selector de color).

## Investigación (fuentes físicas)
- **Capa superficial:** grasa/estrato córneo, dieléctrico con n ≈ 1.44 → F0 = ((n−1)/(n+1))² ≈ 0.028 (Donner & Jensen 2005, d'Eon & Luebke "GPU Gems 3" cap. 14). Rugosidad medida (Weyrich et al. 2006, 149 caras, Torrance–Sparrow): m ≈ 0.3–0.45 → GGX α = 0.35.
- **Dispersión:** con los coeficientes de Jensen et al. 2001 (piel 1: σa = 0.032/0.17/0.48 mm⁻¹, σs′ = 0.74/0.88/1.01 mm⁻¹) el recorrido medio difuso 1/σtr es ≈ 3.7 / 1.4 / 0.7 mm (R/G/B): el rojo se difunde ~5× más lejos que el azul. Aproximación en tiempo real: iluminación envolvente normalizada por canal, (n·l + w)/(1 + w)², con w proporcional a ese recorrido: **w = (0.30, 0.12, 0.06)**. Conserva energía (a n·l = 1 da 1/(1+w) ≤ 1).
- **Albedo/tono:** reflectancia = luminancia lineal del color (como ya hacen los objetos). Presets por categorías ITA de Chardon 1991 (CIELAB medido de piel; ITA = atan((L*−50)/b*)), convertidos a sRGB D65. "Clara" y "Oscura" son los parches "light skin"/"dark skin" de la ColorChecker.

## 3. GLSL común
Añadir esta función **idéntica** en `FS_ESCENA` (render_gl.rs, antes de `main`) y en `FS_PREFIJO` (trazado.rs, antes de `directa`):

```glsl
// Piel: capa grasa dieléctrica (n ≈ 1.44, F0 = 0.028; GGX α = 0.35, Weyrich 2006) sobre un difuso con dispersión
// subsuperficial aproximada por envoltura normalizada por canal (recorrido medio R > G > B, Jensen 2001).
// Radiancia hacia v por una luz en dirección l (unitarias) cuya irradiancia normal es Eperp (color incluido).
vec3 piel_brdf(vec3 n, vec3 v, vec3 l, vec3 alb, vec3 Eperp) {
    const vec3 W = vec3(0.30, 0.12, 0.06);
    const float F0 = 0.028;
    const float A = 0.35;
    float nl = dot(n, l);
    float nv = max(dot(n, v), 1e-3);
    vec3 dif = max(vec3(0.0), (vec3(nl) + W) / ((1.0 + W) * (1.0 + W)));
    float fv = F0 + (1.0 - F0) * pow(1.0 - nv, 5.0);
    vec3 r = alb * dif * ((1.0 - fv) / 3.14159265);
    vec3 hs = l + v;
    if (nl > 0.0 && dot(hs, hs) > 1e-8) {
        vec3 h = normalize(hs);
        float nh = max(dot(n, h), 0.0);
        float a2 = A * A;
        float dd = nh * nh * (a2 - 1.0) + 1.0;
        float D = a2 / (3.14159265 * dd * dd);
        float k = A * 0.5;
        float G = nl / (nl * (1.0 - k) + k) * nv / (nv * (1.0 - k) + k);
        float F = F0 + (1.0 - F0) * pow(1.0 - max(dot(h, v), 0.0), 5.0);
        r += vec3(D * G * F / (4.0 * nv));
    }
    return Eperp * r;
}
```

## 4. Raster (FS_ESCENA, render_gl.rs `main`)
- La carcasa pasa de `vCarcasa > 0.5` a `vCarcasa > 0.5 && vCarcasa < 1.5`; `bool piel = vCarcasa > 1.5;`.
- Guardar la indirecta aparte: `vec3 Eind = uSondaOk == 1 ? ... : uIndirecta; vec3 E = Eind; vec3 Lpiel = vec3(0.0); vec3 v = normalize(uOjo - p);`.
- En el bucle de luces, con `vec3 l = C * inversesqrt(l2);` y `float nl = dot(n, l);`:
  - salta si `per <= 0.0` o si `nl <= (piel ? -0.30 : 0.0)` (la envoltura ilumina un poco más allá del terminador);
  - la sombra y el bias usan `ndl = max(nl, 0.0)` como hoy; para `ndl == 0` el PCSS debe seguir funcionando (si da problemas, usar `max(nl, 0.05)` solo para la sombra);
  - `vec3 Eperp = uColor[i].rgb * (uPosCd[i].w * per / d2 * campo_cercano(i, p, n) * s);`
  - `E += Eperp * ndl;` (la iluminancia de lux sigue siendo la física, sin envoltura) y, si `piel`, `Lpiel += piel_brdf(n, v, l, vAlbedo, Eperp);`.
- Salida: `vec3 rad = piel ? vAlbedo * Eind * (0.972 / 3.14159265) + Lpiel : vAlbedo * E / 3.14159265;` (0.972 = 1 − F0). El modo lux (`uModo == 1`) no cambia.

## 5. Trazado (trazado.rs)
- `Tri` gana `pub piel: bool`. `triangulos_de`: `carcasa: c[0].carcasa > 0.5 && c[0].carcasa < 1.5, piel: c[0].carcasa > 1.5`. Los demás literales (`triangulos_sombra`, prueba ~1419) con `piel: false`.
- Empaquetado (~209): el 4.º componente del albedo es `if t.piel { 1.0 } else { 0.0 }`.
- GLSL: global `bool gPiel = false;` antes de `recorrer`; en `recorrer`, `gPiel = false;` al empezar y `gPiel = ab.w > 0.5;` junto a `albHit = ab.xyz;`.
- Nueva `vec3 directa_piel(vec3 p, vec3 n, vec3 v, vec3 alb, inout uint estado)`: copia de `directa` con dos diferencias: (a) el rechazo `dot(n, Lq) <= 0.0` pasa a `dot(n, Lq) <= -0.30 * dq` (después de calcular `dq`), y (b) devuelve `piel_brdf(n, v, Lq / dq, alb, uColor[k].rgb * W)` (W = suma de pesos, igual que el estimador actual). Ojo: `ocluido` usa `gPiel` indirectamente vía `recorrer`; guardar `bool esPiel = gPiel;` en `camino` justo después de `recorrer` del impacto.
- `camino`: `L += esPiel ? beta * directa_piel(pn, n, -d, alb, estado) : beta * alb * directa(pn, n, estado) / PI;`. El rebote sigue siendo difuso coseno con `beta *= alb` (el especular de la piel es ~3 %, su rebote se desprecia).
